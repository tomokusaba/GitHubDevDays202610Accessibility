# Visual direction

This page is a deliberately flawed accessibility test fixture, not a production interface.

- **THESIS:** Make common accessibility failures visible to automated checks by placing them in one simple static page.
- **OWN-WORLD:** Washed-out grayscale, pale controls, soft geometric illustration, and sparse utility copy.
- **STORY:** A test operator scans and interacts with a plausible landing page, confirming that the audit tool catches missing labels, missing alternative text, weak contrast, ambiguous status colors, role misuse, keyboard failures, a focus trap, and silent state updates.
- **FIRST VIEWPORT:** A pale utility bar, oversized low-contrast headline, unlabeled illustration, and a low-contrast call to action.
- **FORM:** A single page with intentionally omitted semantic structure and scripted interactions that deliberately block or fail to inform keyboard and assistive-technology users.
